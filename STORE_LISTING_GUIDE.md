## 🚀 Step-by-Step Store Listing Setup Instructions

1. **Category Selection**: 
   Go to `Grow` -> `Store presence` -> `Store settings`. Under **App Category**, choose **App**, select category **Tools** or **Productivity**. Add relevant tags like *Tools*, *Security*, and *Productivity*.
2. **Contact Details**:
   Add `jitu1199pal@gmail.com` so users can reach support.
3. **App Content Declaration**:
   Go to `App Content` -> `Advertising ID`. Select **No** because the Charging Alarm Pro builds run with secure sandboxed packages containing zero ad telemetry hooks.
4. **Main Store Listing**:
   Go to `Grow` -> `Store presence` -> `Main store listing`. Fill in the **App Name**, **Short Description**, and **Full Description** using the templates above.
5. **Uploading Visuals**:
   * Drag and drop the downloaded **Feature Graphic** file into the 1024x500 box.
   * Drag and drop the downloaded **Phone Screenshots (1 to 4)** into the phone screenshots carousel.
   * Drag and drop the downloaded **Tablet Screenshots** into the 7-inch and 10-inch carousels, respectively.
6. **Submit for Review**:
   Review all declarations, save changes, and click **Submit for Review** under the publishing overview!
